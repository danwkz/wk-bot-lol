Orb Walker —

Hold the master key — or press it once, in toggle mode — and the cycle runs until you let go (or press it again): the first key stays down the whole time, while the second key and a click where the cursor is take turns, each followed by its own delay.

Master key Starts the cycle from anywhere. While the module is on, the game never sees this key. not set
Toggle Off: the cycle runs while the master key is held. On: one press starts it, the next press stops it.
1 Key to hold Goes down when the cycle starts and comes up when it stops. not set
2 Key to press Tapped once at the start of every cycle. not set
3 Delay after the press The wait between the press and the click. Stopping the cycle cuts it short, with no click. ms
5 Delay after the click The wait between the click and the next press, when the cycle starts again at 2. ms
